# HR Compliance Assistant (FMLA)

Final project — UCSD *Building Agentic AI Systems*.

An HR-admin assistant that, for a selected employee case, retrieves company policy + FMLA law (RAG),
computes leave eligibility, drafts a **cited** determination, flags policy-vs-law conflicts, and routes it
through a human approval gate.

> **Status:** repo initialized; application code not yet built. Planning + full design context live in the
> working cache: `UCSD/Agentic AI System/Final Project/HANDOVER.md` (in the user's Google Drive).

## Setup (to be completed during build)
- Python 3.11+
- `cp .env.example .env` and set `GEMINI_API_KEY` (never commit `.env`)
- `pip install -r requirements.txt`
